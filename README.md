# Basket Product

A small e-commerce application built with JavaScript that allows users to browse products and manage a shopping basket.

## Overview

The application fetches product data from an API, displays products in a catalog, and provides functionality to add products to a shopping basket and remove them.

The project focuses on JavaScript fundamentals, DOM manipulation, asynchronous operations, and Object-Oriented Programming (OOP).

## Features

- Fetching product data from an API
- Displaying product cards dynamically
- Adding products to the shopping basket
- Preventing duplicate products in the basket
- Removing products from the basket
- Switching between the product catalog and the shopping basket
- Updating the UI based on the basket state

## Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- API requests
- DOM manipulation
- Object-Oriented Programming (OOP)

## OOP Concepts

The project demonstrates the use of:

- **Encapsulation** — managing object data and functionality within classes.
- **Inheritance** — extending classes and reusing functionality from parent classes.
- **Polymorphism** — using inherited or overridden methods to provide different implementations of functionality.
